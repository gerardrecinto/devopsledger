Turn one change into a decision record

Fill in a pull request and a Terraform plan. The real parsers and scorers build the record: what changed, how risky it is, whether rollback is documented, and whether a code owner approved. Everything runs in your browser, and the plan below is a made-up sample.

Scores come from the default rule weights, which a YAML file can override in the real service. They rank changes for attention. They are not a safety guarantee.

Why a record, not a dashboard

Six months later nobody remembers why the database was replaced or who said yes. The record keeps the answer next to the change.

1

Capture at the source

GitHub PR webhooks, Terraform or OpenTofu plan JSON, Argo CD sync events and PagerDuty or generic incident webhooks feed one record.

2

Score before it ships

Rule-based risk from environment, action and resource type. Rollback readiness from whether the PR documents a way back. CODEOWNERS approval checked against reviews.

3

Link what happens after

Deployment events, incident correlation and a learning note attach to the same record, so a retro starts from evidence.

Self-hosted, no telemetry

It runs without outbound SaaS calls, works in air-gapped environments after the image pull, and every integration is optional and off by default.

Run it yourself

The repo is an MVP in progress. Docker and Postgres required.

git clone https://github.com/gerardrecinto/devopsledger.git
cd devopsledger
cp .env.example .env   # set POSTGRES_PASSWORD
make up
# API  http://localhost:8000/health
# Web  http://localhost:3000
make test-api   # API tests
make dev        # API with hot reload

Release images are published to ghcr.io/gerardrecinto/devopsledger. See docs/on-prem.md for air-gapped installs.

What this does not do
  • It is not a CI/CD dashboard, a ticketing system or a CMDB.
  • Risk scoring is a weighted rule list, not a model. Tune the weights to your estate.
  • Rollback readiness checks that the description mentions a way back, not that the way back works.
  • This page runs the scoring and parsing only. The database, API and web portal are in the self-hosted package.
